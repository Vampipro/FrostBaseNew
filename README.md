# FROSTBASE v2 — чекер скамерів (Next.js + Prisma + Neon)

Node.js 22+ (підходить 26 LTS).

## Локальний запуск
1. `npm install`
2. Скопіюй `.env.example` → `.env`, заповни:
   - `DATABASE_URL`, `DIRECT_URL` — НОВА база Neon (pooled і direct рядки)
   - `OLD_DATABASE_URL` — стара база (лише для міграції, тільки читається)
   - `SESSION_SECRET` — довгий випадковий рядок
3. `npx prisma db push`      — створити таблиці
4. `npm run db:seed`          — типи (людина/бот/NFT), базові теги, інструкція
5. `npm run migrate:old`      — перенести стару базу (повторно з очищенням: `-- --wipe`), дивись `migration-report.json`
6. `npm run make-admin -- твій_логін`   (або `-- логін пароль`, щоб створити нового)
7. `npm run dev` → http://localhost:3000

Адмін-панель: `/admin` (ролі: admin — усе, moderator — модерація, коментарі, апеляції, бани).
Додати ще адмінів: вкладка «Користувачі» в адмінці.

## Деплой (Vercel + Neon)
1. Залий проєкт у GitHub, імпортуй у Vercel.
2. Змінні оточення: `DATABASE_URL` (pooled), `DIRECT_URL`, `SESSION_SECRET`.
3. Таблиці та міграцію виконай локально (кроки 3–6) проти нової Neon-бази — до чи після деплою.

## Захист від спаму
- Ліміт заявок з одного IP (за замовчуванням 3 за 24 год, змінюється в адмінці)
- Honeypot-поле у формах, перевірка дублів, ліміти на голоси/коментарі/апеляції/реєстрацію/вхід
- Бан IP з адмінки; ліміти рахуються в таблиці `RateLimit` (без Redis)
